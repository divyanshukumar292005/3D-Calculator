🧮 3D Calculator

A simple and stylish 3D Calculator Web App built using HTML, CSS, and JavaScript. It features a modern blue design with interactive buttons for a smooth user experience.

✨ Features

- 🎨 Attractive 3D button design
- ➕ Basic arithmetic operations
- 🔢 Percentage and decimal support
- 🧹 Clear (AC) and Delete (Del) buttons
- 📱 Simple and user-friendly interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 Getting Started

1. Clone this repository:
   
   git clone https://github.com/divyanshukumar292085/3D-Calculator.git

2. Open the project folder.

3. Open "calculator.html" in your web browser.
